# Alexandru Scholler - Portfolio Website

Personal portfolio website showcasing my software engineering projects, skills, and experience.

## 🌐 Live Site
Visit the live site at: [alexscholler.github.io](https://alexscholler.github.io)

## 📋 Features

- **Responsive Design**: Fully responsive across desktop, tablet, and mobile devices
- **Dark Mode**: Modern dark theme with smooth animations
- **Project Showcase**: Featured projects including detailed case studies
- **Interactive UI**: Smooth scrolling, reveal animations, and dynamic navigation
- **Contact Form**: Integrated contact section for professional inquiries

## 🛠️ Technologies Used

- **HTML5**: Semantic markup and structure
- **CSS3**: Custom styling with animations and transitions
- **JavaScript**: Interactive features and DOM manipulation
- **Font Awesome**: Icon library for visual elements
- **Google Fonts**: Poppins font family for typography

## 📁 Project Structure

```
alexscholler.github.io/
├── index.html          # Main portfolio page
├── handovr.html        # Handovr product page (eQualsFortyTwo Ltd)
├── case-study.html     # Early Handovr prototype case study
├── education-journey.html # Education timeline
├── style.css           # All styles and responsive design
├── images/             # Image assets
└── README.md           # This file
```

## 🚀 Key Sections

1. **Hero Section**: Introduction with profile photo and social links
2. **About Me**: Background, skills, and expertise
3. **My Company**: eQualsFortyTwo Ltd and its product, Handovr
4. **Featured Projects**: Showcase of technical projects with links
5. **Contact**: Professional contact information and form
